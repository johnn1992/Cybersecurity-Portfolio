# Lab 1 – Basic Scan

## Objective

Learn how to perform a basic Nmap scan to discover active hosts and open ports on a target.

## Command Used

```bash
nmap scanme.nmap.org
```

## Explanation

This command performs a basic TCP scan against the target host. It identifies open TCP ports and provides a basic overview of the target's network services.

## Key Findings

- Successfully scanned the target host.
- Identified open TCP ports.
- Learned how a basic Nmap scan works.
