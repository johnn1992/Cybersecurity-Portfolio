# Nmap Basic Scan

## Overview
This lab demonstrates a basic Nmap scan used to discover open ports and services running on a target machine.

## Command Used

nmap <target-ip>

## Findings
The scan was used to identify:
- Open ports
- Available services
- Basic network information about the target
