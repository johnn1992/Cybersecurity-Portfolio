# Sysmon Event Analysis

## Overview
Sysmon (System Monitor) is a Windows tool from Microsoft Sysinternals that provides detailed logging of system activity. It helps security analysts monitor and investigate suspicious activity.

## Event ID 1 - Process Creation
Event ID 1 records when a new process starts. It shows information such as the process name, command line, parent process, and user account.

## Event ID 5 - Process Terminated
Event ID 5 records when a process ends. It helps analysts track the lifecycle of processes running on a system.

## Conclusion
Sysmon events are useful for threat detection, incident response, and investigating suspicious activity on Windows systems.
