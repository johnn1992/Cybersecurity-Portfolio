# Autopsy Digital Forensics Lab

## Overview
This lab demonstrates the use of Autopsy Digital Forensics software to analyze a forensic image and identify files contained within the evidence source.

## Tool Used
- Autopsy 4.23.1

## Objectives
- Create a forensic investigation case
- Add a digital evidence source
- Analyze disk volumes and file systems
- Locate extracted files
- Generate an HTML forensic report

## Investigation Steps
1. Created a new case in Autopsy.
2. Added the provided forensic image as a data source.
3. Enabled analysis modules.
4. Examined available volumes and file locations.
5. Identified files within the analyzed evidence.
6. Generated an HTML report containing investigation results.

## Findings
- Successfully loaded and analyzed the forensic image.
- Multiple volumes were identified during analysis.
- Files were recovered and reviewed from the evidence source.
- An HTML report was successfully generated.
